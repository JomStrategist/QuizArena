Solution Sheet — Understand the Difference

Review the clue behind every answer before moving to Activity 2.

Traditional Machine Learning

Think: rows and columns. Structured information such as customer data, sales, prices or transactions. Used to predict a number or category.

Deep Learning

Think: neural networks. A type of Machine Learning that is especially useful for complex patterns and many examples.

NLP

Think: words and language. Emails, documents, conversations, speech, translation and summaries.

Computer Vision

Think: eyes. Photographs, camera feeds, scans and video.

Key idea: Deep Learning is a method inside Machine Learning. NLP and Computer Vision describe the type of problem/data. A real solution can use these concepts together.
